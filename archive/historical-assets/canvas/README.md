# Historical Canvas Asset Archive

> **Status: HISTORICAL / NON-RUNTIME / NON-AUTHORITATIVE.**

This directory preserves the twelve unresolved or potentially unique image files
removed from the obsolete `.canvas` tool directory during the M0-P3E provenance
cleanup. The files are retained byte-for-byte under their original filenames for
future reference and engine-migration investigation.

These images are not application assets and must not be imported into runtime
code. Current canonical assets remain under `frontend/assets/`. The complete
pre-cleanup paths, SHA-256 hashes, sizes, classifications, canonical counterparts,
and final dispositions are recorded in
`docs/asset-provenance-manifest.md`.
