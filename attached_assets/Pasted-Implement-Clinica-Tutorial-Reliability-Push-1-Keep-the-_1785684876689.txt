## 1. Normalize learner-profile IDs

Normalize legacy values as follows:

* `nonmedical`, `rpg`, `cozy`, `teen` → `curious`
* `nursingStudent`, `preNursing`, `medical_learner` → `nursing_student`
* `nclexPrep` → `nclex`
* `healthcareProfessional` → `professional`

Apply normalization when player data is loaded or migrated so downstream systems receive canonical values.

Preserve compatibility for existing saved accounts.

Verify that normalized `nursing_student` behavior uses:

* Practiced tutorial tier
* Standard feedback depth
* No novice starting handicap
* Clinical default difficulty
* Existing nursing-student star rules

Do not change the behavior of canonical `curious`, `nclex`, or `professional` profiles.

## 2. Correct systemHubIntro silent completion

Inspect the no-hero or invalid-player-state branch that directly calls:

`markDone("systemHubIntro")`

Do not silently mark the tutorial completed unless the player actually viewed or intentionally skipped it.

Use a safe recovery state instead:

* Repair or redirect the invalid player state
* Leave `systemHubIntro` uncompleted
* Allow the tutorial to run normally once the hub is valid

Preserve the intentional decision that `systemHubIntro` is excluded from normal Tutorial Center replay unless changing that behavior is necessary to prevent permanent loss.

Fix only confirmed tutorial-flow defects. Do not redesign summoning, pity, or duplicate systems in this push.

## 4. Add tutorial-state tests

* Completing a tutorial
