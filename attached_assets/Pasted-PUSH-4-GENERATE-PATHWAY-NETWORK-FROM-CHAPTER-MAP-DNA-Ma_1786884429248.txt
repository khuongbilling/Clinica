PUSH 4 — GENERATE PATHWAY NETWORK FROM CHAPTER MAP DNA

MapDNA now defines the personality of the map.

Convert that DNA into an abstract PATHWAY GRAPH before generating hexes
or scenery.

==================================================
1. CREATE PATH GRAPH
==================================================

Represent the map first as:

nodes
+
connections

Node types:

START
JUNCTION
CLEARING
LANDMARK
TRANSITION
FINAL_APPROACH
GATE

Edges represent broad traversable lanes.

Example:

START
  |
JUNCTION
 /      \
CLEAR   PATH
 |       |
PATH   CLEAR
  \     /
 JUNCTION
    |
   GATE

This logical graph exists BEFORE hex coordinates.

==================================================
2. PATH GRAPH FROM TOPOLOGY FAMILY
==================================================

Each topology family provides rules, not exact positions.

Example:

OPEN PLAZA:
- 1–2 central junctions
- high connectivity
- 2–4 loops
- short route lengths

ACADEMIC QUAD:
- 3–5 junctions
- 2–4 loops
- pathways around obstacle islands

SIMULATION COMPLEX:
- 1 primary spine
- 3–6 branches
- 1–3 loops

HUB AND SPOKE:
- 1 main hub
- 4–6 branches
- reconnect 1–3 branches

TWIN HUB:
- 2 major hubs
- 2–4 independent connectors between hubs

BRAIDED:
- 2–3 major route strands
- reconnect repeatedly

PROMENADE:
- 2–4 sequential hubs
- side loops

etc.

==================================================
3. NO SINGLE-LINE MAPS
==================================================

Unless a specific future Chapter explicitly calls for it:

reject maps where:

start → gate

has only one possible route for most of the Chapter.

Chapters should generally provide tactical exploration choices.

Require:

multiple route alternatives across meaningful portions of the map.

==================================================
4. PATH WIDTH
==================================================

Primary traversal lanes:

2–3 hexes wide.

Secondary routes:

1–2 hexes wide.

Avoid long stretches of one-hex corridors.

A one-hex choke may exist occasionally for deliberate dramatic purposes,
but should not define the entire map.

==================================================
5. ROUTE LENGTH
==================================================

Do not place start and gate adjacent in graph distance.

Suggested minimum shortest-route distance:

roughly 35–50% of the total map's effective diameter.

Players should traverse meaningful portions of the Chapter.

==================================================
6. LOOPS
==================================================

Loops are valuable because they:

- create exploration choices
- allow alternate approaches
- reduce backtracking
- make larger maps feel less linear

For 60-tile maps:

normally target:
2–4 meaningful loops

For 70-tile maps:

normally:
2–5 meaningful loops

Topology may modify these values.

==================================================
7. DEAD ENDS
==================================================

Dead ends are allowed only when they reward exploration.

A dead-end branch should normally terminate in:

- treasure opportunity
- Ward Event clearing
- merchant clearing
- secret/rare encounter
- narrative landmark

Do not generate meaningless dead ends.

==================================================
8. VALIDATE GRAPH BEFORE HEXES
==================================================

Reject pathway graph if:

- gate unreachable
- disconnected region exists
- too linear
- excessive dead ends
- no meaningful loop
- start/gate too close
- topology signature too similar to another Chapter

Only after graph passes:

continue to spatial embedding.
