Before Night is unlocked, don't render its actual nodes and then CSS-hide them.

Don't send the node details to this component at all.

type ShiftAvailability = {
  day: boolean;
  evening: boolean;
  night: boolean;
};

type ShiftSelectorProps = {
  availability: ShiftAvailability;
  activeShift: "day" | "evening" | "night";
  onSelect:
    (
      shift:
        | "day"
        | "evening"
        | "night",
    ) => void;
};

export function ShiftSelector({
  availability,
  activeShift,
  onSelect,
}: ShiftSelectorProps) {
  return (
    <div
      className="journey-shift-selector"
      role="tablist"
      aria-label="Ward shift"
    >
      <button
        role="tab"
        aria-selected={
          activeShift === "day"
        }
        onClick={() => onSelect("day")}
      >
        Day Shift
      </button>

      {availability.evening ? (
        <button
          role="tab"
          aria-selected={
            activeShift === "evening"
          }
          onClick={() =>
            onSelect("evening")
          }
        >
          Evening Shift
        </button>
      ) : null}

      {availability.night ? (
        <button
          role="tab"
          aria-selected={
            activeShift === "night"
          }
          onClick={() =>
            onSelect("night")
          }
        >
          Night Shift
        </button>
      ) : (
        <button
          type="button"
          disabled
          aria-label="Night Shift is revealed through the story"
          className="journey-shift-teaser"
        >
          <span>Night Shift</span>
          <small>
            Revealed through the story
          </small>
        </button>
      )}
    </div>
  );
}

For Evening, you can either use the same teaser concept before Chapter 3 or keep it completely hidden until unlocked. I favor:

Evening teaser after Chapter 2.
Evening opens after Chapter 3.
Night teaser begins after Evening unlock.
Night opens after Chapter 6.

This gives anticipation without throwing actual Night content at a new player.
