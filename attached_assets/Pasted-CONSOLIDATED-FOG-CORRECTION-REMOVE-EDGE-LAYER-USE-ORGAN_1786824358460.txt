==================================================
8. SOFT LOBE PRIMITIVE
==================================================

A radial gradient may be used INTERNALLY as a brush primitive.

That does NOT mean the final reveal may look circular.

Example concept:

function eraseSoftLobe(
  ctx,
  x,
  y,
  radius,
  strength
) {
  const gradient =
    ctx.createRadialGradient(
      x,
      y,
      radius * 0.12,
      x,
      y,
      radius
    );

  gradient.addColorStop(
    0,
    `rgba(0,0,0,${strength})`
  );

  gradient.addColorStop(
    0.45,
    `rgba(0,0,0,${strength * 0.92})`
  );

  gradient.addColorStop(
    0.75,
    `rgba(0,0,0,${strength * 0.45})`
  );

  gradient.addColorStop(
    1,
    "rgba(0,0,0,0)"
  );

  ctx.fillStyle = gradient;

  ctx.fillRect(
    x - radius,
    y - radius,
    radius * 2,
    radius * 2
  );
}

Then combine several overlapping irregular lobes.

A single radial gradient is NOT sufficient.
