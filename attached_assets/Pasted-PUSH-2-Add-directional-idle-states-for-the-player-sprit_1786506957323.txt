PUSH 2 — ADD DIRECTIONAL IDLE FACING FOR EXPLORATION SPRITE

Do not change:
- player stats
- camera logic
- fog logic
- encounter rules
- map layout

Current issue:
The exploration sprite does not visually react enough to movement direction.

Goal:
The character should face the direction of the most recent movement and remain in that facing while idle.

Implement a directional facing system for the exploration sprite.

Use 6-direction facing because the map is hex-based.

Required facing states:
- face_e
- face_w
- face_ne
- face_nw
- face_se
- face_sw

Behavior:
1. When the player moves to a new hex, determine the movement vector.
2. Resolve the movement vector into one of the 6 hex directions.
3. After movement completes, set the player’s idle facing to that direction.
4. While standing still, keep the last facing direction.

For this push, directional facing may be implemented using:
- either unique directional sprite frames
- or mirrored variants where appropriate

At minimum:
- leftward movement should end with a left-facing idle
- rightward movement should end with a right-facing idle
- diagonal hex movement should end with the matching diagonal idle

If full 6 unique facings are not yet available as separate art,
support the state system first so art can be expanded later.

Add a very subtle idle presence:
- tiny bob
- or tiny breathing motion
- or gentle cape/coat sway

Keep it restrained.
This is not combat animation.

Acceptance:
- Sprite changes facing based on last movement direction
- Character remains facing that direction while idle
- Idle state feels alive, not frozen
- No movement bugs introduced
