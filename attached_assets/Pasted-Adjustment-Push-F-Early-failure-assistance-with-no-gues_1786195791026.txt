Adjustment Push F — Early-failure assistance with no guessing

This should be scenario-authored, not generated by the battle UI.

Every tutorial/early encounter can optionally provide hint rules.

Types
export interface BattleAssistRule {
  afterConsecutiveFailures: number;

  mentorText: string;

  /**
   * Optional existing battle action identifier.
   * UI may highlight it.
   */
  highlightActionId?: string;

  /**
   * Optional existing target/threat id.
   */
  highlightTargetId?: string;
}

export interface BattleAssistConfig {
  enabled: boolean;

  /**
   * Battle retry itself costs nothing additional.
   *
   * IMPORTANT:
   * Do NOT refund Journey stamina already spent
   * moving onto this map tile.
   */
  freeBattleRetry: boolean;

  rules: BattleAssistRule[];
}

Example Chapter 1 configuration:

export const chapter1BattleAssist:
  BattleAssistConfig = {
  enabled: true,
  freeBattleRetry: true,

  rules: [
    {
      afterConsecutiveFailures: 1,

      mentorText:
        "The patient's stability is falling faster than the other threats. Look at what is acting next.",
    },

    {
      afterConsecutiveFailures: 2,

      mentorText:
        "Resolve the immediate threat before committing actions to the lower-risk problem.",

      highlightActionId:
        "focused-assessment",

      highlightTargetId:
        "acute-respiratory-threat",
    },
  ],
};

Then resolve assistance with one pure function:

export function getBattleAssistRule(
  config: BattleAssistConfig | undefined,
  consecutiveFailures: number,
): BattleAssistRule | null {
  if (
    !config?.enabled ||
    consecutiveFailures <= 0
  ) {
    return null;
  }

  const eligible =
    config.rules
      .filter(
        (rule) =>
          consecutiveFailures >=
          rule.afterConsecutiveFailures,
      )
      .sort(
        (a, b) =>
          b.afterConsecutiveFailures -
          a.afterConsecutiveFailures,
      );

  return eligible[0] ?? null;
}

On failure:

export interface EncounterAttemptState {
  consecutiveFailures: number;
}

export function recordEncounterFailure(
  state: EncounterAttemptState,
): EncounterAttemptState {
  return {
    ...state,
    consecutiveFailures:
      state.consecutiveFailures + 1,
  };
}

export function recordEncounterVictory(
  state: EncounterAttemptState,
): EncounterAttemptState {
  return {
    ...state,
    consecutiveFailures: 0,
  };
}

Persist consecutiveFailures with the specific encounter attempt, not globally.
