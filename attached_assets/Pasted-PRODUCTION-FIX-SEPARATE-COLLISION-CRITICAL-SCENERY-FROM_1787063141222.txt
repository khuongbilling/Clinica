PRODUCTION FIX — SEPARATE COLLISION-CRITICAL SCENERY FROM THE RASTER BACKGROUND

Current screenshot confirms:

✓ Blueprint active
✓ 60-cell Chapter 1 map active
✓ World 876 × 722
✓ Camera correct
✓ Fog/FOV correct
✓ New simulation-university background active

BUT:

The generated raster still paints hospital beds, consoles and other raised
objects underneath playable hexes.

Therefore the current strategy is not reliable enough:

BLUEPRINT
→ AI paints complete furnished environment
→ hexes placed on top

The AI artwork can approximate the blueprint but cannot guarantee
pixel-accurate obstacle avoidance.

Change the production architecture.

==================================================

Regenerate Chapter 1's base raster using the SAME:

✗ large machines
✗ planters

==================================================

Merge them into the existing continuous walkable bed.

- flat textures

If a character could not physically walk across something,
it does not belong inside the bed.

==================================================

==================================================
6. KEEP AN ADDITIONAL BUFFER FROM WALKABLE HEXES
==================================================

Do not merely prevent literal polygon overlap.

Large objects should also maintain visual breathing room.

Suggested safety separation:

normal prop:
0.15–0.20 × tile size

large prop:
0.25–0.35 × tile size

from playable footprint.

This prevents beds/counters from visually intruding into a hex even if
their collision polygons technically do not cross.
