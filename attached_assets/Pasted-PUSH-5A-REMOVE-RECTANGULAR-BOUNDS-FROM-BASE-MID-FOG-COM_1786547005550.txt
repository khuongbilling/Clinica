PART 1 — USE ONE FULL-WORLD CANVAS PER FOG LAYER

FogBaseLayer and FogMidLayer must each use a canvas sized to the ENTIRE MapWorld.

Example:

baseFogCanvas.width = worldWidth;
baseFogCanvas.height = worldHeight;

midFogCanvas.width = worldWidth;
midFogCanvas.height = worldHeight;

Do NOT create:
- one canvas per quadrant
- one canvas per visible region
- one canvas per tile
- separate rectangular fog sections

There should be exactly:

1 Base Fog canvas
1 Mid Fog canvas

for the whole map world.

PART 2 — DRAW MULTIPLE TRANSPARENT FOG SPRITES INSIDE THE CANVAS

Do not stretch one fog PNG across the world.

Instead:

- clear the full-world canvas
- draw several copies of the approved fog asset
- overlap them
- vary their positions
- vary scale moderately
- vary opacity
- vary rotation slightly

The rectangular source-image bounds must remain invisible because the PNG/WebP exterior is transparent.

1. clear transparent canvas
