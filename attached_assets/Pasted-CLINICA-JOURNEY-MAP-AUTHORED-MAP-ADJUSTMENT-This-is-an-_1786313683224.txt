CLINICA JOURNEY MAP — AUTHORED MAP ADJUSTMENT

This is an adjustment to the Journey map system that already exists.

DO NOT rewrite:
- canonicalEncounters.ts
- wardEventSubtypes.ts
- TimeOfDay
- chapter progression
- boss key progression
- fog-of-war rules
- encounter persistence
- battle generation
- JourneyRun persistence
- stamina rules
- bottom navigation
- existing shift unlock logic

The existing procedural ENCOUNTER generation remains.

CHANGE ONLY THE PHYSICAL MAP GEOMETRY AND MAP PRESENTATION.

NEW CANONICAL RULE:

Each Chapter owns one fixed authored hex-map template.

The following remain fixed for that Chapter:
- exact hex coordinates
- overall map shape
- total tile count
- starting tile
- Chapter Boss Gate tile
- major environmental composition

They DO NOT change when the player regenerates/rechallenges the Chapter.

A new Chapter attempt randomizes:
- Battle tiles
- Area Boss tiles
- Treasure
- Traveling Merchant
- Ward Events
- Ward Event subtypes
- treasure tier
- temporary chapter rewards
- fog/revealed state
- temporary Call Team
- temporary Cards
- temporary Blessings
- temporary Hazards

Do not generate separate floating islands.

All playable hex tiles must physically touch another playable hex by a full edge and collectively form one connected terrain footprint.

Do not add modular bridge/path graphics between separated hex tiles.

No Encounter tiles are intentional traversable terrain and function as the connective spaces of the map.

DAY / EVENING / NIGHT:

All three shifts use the SAME Chapter geometry:
- same coordinates
- same start
- same Boss Gate
- same major landmarks

Shift changes:
- encounter distribution according to the existing shift system
- Ward Event flavour
- pressure mechanics
- combat orchestration
- environmental artwork
- ambient lighting/fog treatment

Do not change geometry when switching shifts.

The current dark map environment should be treated as the NIGHT visual direction, not the default visual identity for every shift.

FINAL ART RULE:

Do not simulate final Day/Evening/Night environmental artwork using CSS filters.

Use dedicated raster PNG/WebP artwork for final shift environments and atmospheric art.

Implement in small sequential pushes.
