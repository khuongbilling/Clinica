THE BLUEPRINT IS THE AUTHORITATIVE MAP.

→ Scenery Dressing
→ Final Raster Background

→ Encounters / Objects

==================================================
1. BLUEPRINT FIRST
==================================================

The current Chapter blueprint already establishes:

- exact playable hex cells
- primary lanes
- secondary lanes
- transitions
- junctions
- clearings
- start
- gate
- world bounds
- scenery exclusion areas

Treat this as authoritative world geometry.

Do NOT modify the blueprint to fit existing background artwork.

The artwork must fit the blueprint.

==================================================
2. CREATE A WALKABLE ENVIRONMENT BED
==================================================

Before generating scenery, convert the blueprint into one continuous
WALKABLE BED.

This is not a debug overlay.

It is the actual environmental floor layout that the final raster artwork
will depict.

Conceptually:

Blueprint Hex Cells
        ↓
Merge adjacent walkable hexes
        ↓
Continuous floor/path polygons
        ↓
Widen lanes and clearings naturally
        ↓
Environment floor bed

The floor bed should visually connect adjacent cells so the final map does
NOT look like individual hex tiles pasted onto an image.

==================================================
3. PATH BED TYPES
==================================================

Translate blueprint zones into environmental flooring.

PRIMARY LANE:

broad major university walkway

approximately enough visual width for:
2–3 movement hexes

SECONDARY LANE:

smaller circulation path

approximately:
1–2 movement hexes

TRANSITION:

gradual widening/narrowing between lane and clearing

CLEARING:

large uninterrupted open floor region

JUNCTION:

open intersection where several routes naturally meet

FINAL APPROACH:

visually important path leading toward Chapter gate / final area

==================================================
4. CLEARINGS MUST BE PART OF THE BED
==================================================

Do not create lanes first and then drop circles on them.

A clearing should be an organic widening of the same walkable floor system.

Examples:

lane
→ wider transition
→ training court

or:

multiple lanes
→ broad intersection
→ simulation plaza

Clearing shapes may include:

- irregular training court
- rectangular-ish academic court
- oval assessment space
- offset plaza
- widened intersection
- open simulation bay

Avoid making all clearings circles.

==================================================
5. MERGE HEXES INTO NATURAL PATHS
==================================================

The player movement system remains hex-based.

But the raster environment should NOT visibly reveal that the walkable
surface was produced from individual hexes.

Use the hex footprint as geometry input.

Then smooth/merge the external pathway boundary.

The final floor should read as:

continuous architecture

not:

60 connected hexagons.

Hex outlines remain a gameplay overlay rendered later.

==================================================
6. CREATE WALKABLE SAFETY REGION
==================================================

From the floor bed create:

walkableSafetyMask

This includes:

entire floor bed
+
small safety margin

Suggested safety margin:

approximately 0.20–0.30 × tile size

Major scenery may NOT intersect this region.

This protects:

- character movement
- chest placement
- merchant placement
- Ward Events
- normal enemies
- Area Bosses
- readable FOV
