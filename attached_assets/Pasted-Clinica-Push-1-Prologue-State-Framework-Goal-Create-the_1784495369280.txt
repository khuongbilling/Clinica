Clinica Push 1: Prologue State Framework

Goal:
Create the safe state framework for the new opening prologue without fully building every cinematic yet.

Add a new opening sequence structure for brand-new players only. Existing players must keep their current characters, progress, rewards, roster, and onboarding state.

New opening flow states:
1. opening_memory_cinematic
2. former_self_battlefield_cutscene
3. silent_infarction_initial_reveal
4. former_self_support_loadout
5. opening_battle_tutorial
6. scripted_defeat
7. lotus_recall_cinematic
8. identity_reconstruction_character_creation
9. post_rebirth_awakening
10. memory_echo_award_scene
11. clinica_university_introduction

Temporary prologue identifiers:
- prologue_former_self
- prologue_nightingale_legendary
- prologue_fleming_legendary
- prologue_master_bai
- prologue_silent_infarction

Permanent post-rebirth identifiers:
- nightingale_memory_echo
- fleming_memory_echo
- nightingale_legendary_locked
- fleming_legendary_locked

Rules:
- Brand-new players should enter the new prologue framework before permanent character creation.
- Returning players should not be forced into the prologue.
- Existing players should not lose characters or progress.
- Temporary prologue heroes must never transfer into the permanent roster.
- Add safe save and resume checkpoints for each major opening phase.
- If the app closes during onboarding, resume from the closest safe checkpoint.
- Prevent duplicate rewards.
- Archive replay can be placeholder only for now, but replay must not modify roster or saved progress.
- Add a development-only hidden scene tester for jumping to each prologue phase, but do not expose it in production.

Acceptance checks:
- Existing players still load normally.
- New players route into the new prologue sequence framework.
- Prologue phase flags are saved and resumable.
- No duplicate rewards can be created.
- Temporary prologue IDs are separate from permanent roster IDs.
- App still builds and existing Ward Shift, University, Heroes, Shop, Realm, and Battle routes continue working.
