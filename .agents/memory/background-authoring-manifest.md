## Rule

The authoring manifest is a metadata contract, not visual proof. A finished
journey-map raster must match its exact active geometry identity and source
path, and shift variants for one environment must also preserve the same
landmark composition.

**Why:** Matching hashes and a “validated” status cannot detect independently
generated day/evening/night paintings that move courts, paths, or landmarks.

**How to apply:** Keep one approved master composition for a map and create
other shifts as lighting-only derivatives. Preserve the normal manifest/Stage 3
identity checks and use a lighting-tolerant visual-structure test before
approving the complete shift set.
